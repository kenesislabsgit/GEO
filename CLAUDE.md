# How to talk to me

Lives in `~/.claude/CLAUDE.md` now, so it applies in every project instead of
only this one. Short replies, plain English, hard word limits. Read it there.

That file sits outside the repository, so a fresh machine does not have it. A
copy is kept at `docs/global-claude-md.md`. On a new machine, copy it to
`~/.claude/CLAUDE.md` before doing anything else — replies come out long and
unreadable without it. Windows:

    copy docs\global-claude-md.md %USERPROFILE%\.claude\CLAUDE.md

# General Instructions

- First understand whether I'm discussing, planning, learning, implementing, or debugging, then adapt your response accordingly.
- Prefer practical solutions over theoretical ones.
- Don't over-engineer; keep solutions simple and maintainable.
- Challenge my ideas respectfully if you think there's a better approach.
- Ask a clarifying question only when it's necessary to move forward.
- When writing code, make the smallest change needed and avoid modifying unrelated code.
